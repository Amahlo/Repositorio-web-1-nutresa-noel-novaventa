#HISTORIAS DE USUARIOS

##👩‍💻ESTUDIANTE : DEERLY JHARIK HERNANDEZ MISAS

###COMO desarrollador
###QUIERO desarrollar una funcionalidad de historial de consumo en el módulo Despensa de la página web Sazón
###PARA que el usuario pueda visualizar, consultar, utilizar y editar el registro de los productos que ha consumido.

###🗒️CRITERIOS DE ACEPTACIÓN 

1. 👁️Visualizar historial: El sistema debe permitir al usuario visualizar su historial de consumo, mostrando los productos registrados, las cantidades y las fechas correspondientes.

2. 🔎Consultar registros: El sistema debe permitir al usuario buscar y filtrar los registros de consumo por nombre del producto o por fecha.

3. ✏️Editar registros: El sistema debe permitir al usuario modificar la información de un registro existente, como la cantidad consumida, la fecha o el producto.

4. 💻Utilizar el historial: El sistema debe permitir al usuario consultar sus consumos anteriores para identificar los productos que utiliza con mayor frecuencia y apoyar la planificación de sus compras.

5. 💾Guardar cambios: El sistema debe guardar las modificaciones realizadas y actualizar el historial para que el usuario pueda visualizar la información actualizada.
